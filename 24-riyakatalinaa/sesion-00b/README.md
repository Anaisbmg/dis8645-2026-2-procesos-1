 ### apuntes sobre la charla
 - Heidi Jalkh es diseñadora experimental
 - explorar de manera distinta la forma de pensar en los materiales enfocada en el diseño experimental
 - bio-inspirados utilizan la estructura celular y la absorción del agua para así modificar su propia forma y funcionamiento
 - bio-fabricación es el proceso de crear un material a través del mundo fungí, utilizando mallas/grillas que les permite oxigenación para darle forma, color y generar estructura
 - bio-basados consisten en utilizar residuos y desechos para la creación de un nuevo material, mediante métodos de elaboración manual
 - en este taller se utilizará cobre como material principal para investigar sus distintas aplicaciones (material no antes utilizado por Heidi)
