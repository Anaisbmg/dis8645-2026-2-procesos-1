3- FAAD, Republica 180 
Curiosamente la faad tiene un botón para bajar y otro para subir, a simple vista se ve que el botón para subir tiene un mayor uso ya que este tiene mayor rastro, dentro existen los números de 4 al -1 ordenados en forma zig zag o diagonal, existen los botones con braille y con volumen de la silueta del icono, también existe un lugar para poder insertar una llave.
