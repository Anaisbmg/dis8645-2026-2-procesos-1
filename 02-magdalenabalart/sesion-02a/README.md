## Introducción a electricidad y componentes

Luego comenzamos a revisar conceptos eléctricos:

### **<ins>Átomos</ins>**

Unidad básica que compone la materia.

Todo lo que nos rodea está formado por átomos: los cables, las resistencias, la protoboard, nuestro cuerpo, etc.

Un átomo contiene:
```text
**Protones:** tienen carga positiva.
**Electrones:** tienen carga negativa.
**Neutrones:** no tienen carga eléctrica.
```
Los protones y neutrones se encuentran en el núcleo. Los electrones se encuentran alrededor del núcleo.


![átomos](imagenes/.jpg)


**<ins>Carga eléctrica</ins>**

Propiedad de las partículas que permite que exista atracción o repulsión eléctrica.

Existen dos tipos:

**Carga positiva + 
Carga negativa −**

Las cargas opuestas se atraen y las cargas iguales se repelen.

### **<ins>Ion</ins>**

Átomo que posee carga eléctrica porque ganó o perdió electrones.

>Si pierde electrones, queda con carga positiva.
>Si gana electrones, queda con carga negativa.

Un átomo neutro tiene la misma cantidad de protones y electrones. Un ion posee un desequilibrio entre ambos.

![iones](imagenes/.jpg)

### **<ins>Energía</ins>**

Capacidad de producir un cambio o realizar trabajo.

La energía no es solamente movimiento, aunque puede manifestarse como movimiento. También puede almacenarse o transformarse.

Ejemplos:
```text
-Energía eléctrica.
-Energía térmica.
-Energía química.
-Energía luminosa.
-Energía cinética o de movimiento.
```
Una batería almacena energía química y puede transformarla en energía eléctrica.

### **<ins>Electricidad</ins>**

Conjunto de fenómenos producidos por la presencia y el movimiento de cargas eléctricas.

En un cable metálico, lo que se desplaza principalmente son los electrones, no los átomos completos.

Por eso, es más correcto decir:

**La corriente eléctrica es un flujo de cargas eléctricas.**
 
No es exactamente un flujo de átomos ni un flujo de energía. Las cargas se mueven y mediante ese movimiento, se transfiere energía.

Comparación con el agua

se puede imaginar un circuito eléctrico como un sistema de tuberías:

| Sistema de agua | Circuito eléctrico |
|---|---|
| Agua | Cargas eléctricas |
| Caudal | Corriente |
| Presión | Voltaje |
| Tubería estrecha | Resistencia |
| Bomba | Fuente de alimentación o batería |
 
### **<ins>Electrodo</ins>**

Un electrodo es un material conductor que permite conectar un circuito eléctrico con otro medio, por ejemplo:
```text
-El cuerpo humano.
-El cuero cabelludo.
-Un líquido.
-Una batería.
-Otro material conductor.
```
Su función general es permitir el intercambio o la detección de señales eléctricas entre el circuito y ese medio.

Actividad neuronal
        ↓
Movimiento de iones en las neuronas
        ↓
Se generan campos eléctricos
        ↓
Aparecen pequeñas diferencias de voltaje en el cuero cabelludo
        ↓
Los electrodos permiten medirlas
        ↓
El amplificador del EEG registra la señal

```text
-Dentro del cuerpo, la corriente se produce principalmente mediante el movimiento de iones.
-En los cables del equipo, la corriente se transporta principalmente mediante electrones.
-El electrodo funciona como la interfaz entre la conducción iónica del cuerpo y la conducción electrónica del circuito.
```

### **<ins>Voltaje</ins>**

El voltaje es la diferencia de potencial eléctrico entre dos puntos. Es como el “empuje” que hace posible el movimiento de las cargas eléctricas por un circuito.

**Se mide en voltios = V.**

El voltaje siempre se mide entre dos puntos, utilizamos GND (tierra) como referencia:
```
-GND corresponde a 0 V.
-Un punto de 3,3 V tiene una diferencia de 3,3 V respecto de GND.
-Un punto de 5 V tiene una diferencia de 5 V respecto de GND.
```
### **<ins>Corriente</ins>**

La corriente eléctrica corresponde al flujo de carga que circula por un circuito.

**Se mide en amperios (A)**

El voltaje y la corriente están relacionados, pero no son lo mismo:
```
-El voltaje es la diferencia que impulsa las cargas.
-La corriente es el flujo de cargas producido.
```
### **<ins>Potencia y energía</ins>**

Se relacionan pero potencia y energía no significan lo mismo.

**Potencia**:

La potencia indica la rapidez con que un dispositivo consume, entrega o transforma energía.

Se mide en watts (W).

La relación básica es:

> P=V×I

Donde:
```
P: potencia en watts.
V: voltaje en voltios.
I: corriente en amperios.
```
**Energía**:

La energía corresponde a la cantidad total utilizada durante un periodo determinado.

> E=P×t

Por ejemplo, dos dispositivos pueden utilizar la misma potencia, pero el que permanece encendido durante más tiempo consume más energía.
 
**Potencia: qué tan rápido se utiliza energía.
Energía: cuánto se utilizó en total.**  

Resistencias

Una resistencia es un componente que se opone al paso de la corriente eléctrica. Su valor se mide en ohmios (Ω).

Las resistencias se utilizan para:

```
Limitar la corriente.
Proteger componentes.
Establecer estados lógicos.
Dividir voltajes.
Evitar que una entrada quede flotante.
```

La relación entre voltaje, corriente y resistencia se expresa mediante la ley de Ohm:

> V=I×R

### **<ins>Potenciómetro</ins>**

Un potenciómetro es una resistencia variable, al girar su perilla o desplazar su control, cambia la posición de un contacto interno llamado cursor o wiper.

posee tres patas:
```
Un extremo de la pista resistiva.
La pata central o cursor.
El otro extremo de la pista.
```
Una conexión habitual es:
```
Extremo 1  → 5 V o 3,3 V
Centro     → entrada analógica
Extremo 2  → GND
```
**Potenciómetro como divisor de voltaje**

El cursor divide internamente la pista resistiva en dos resistencias:
```
Voltaje de alimentación
        │
       R1
        │
        ├── Voltaje de salida
        │
       R2
        │
       GND
```
Cuando movemos el potenciómetro:

R1 aumenta mientras R2 disminuye, o viceversa.
Cambia la proporción entre ambas resistencias.
Cambia el voltaje obtenido en la pata central.

> Encoder: también puede girar, pero no funciona igual que un potenciómetro. Registra cambios de posición o pasos mediante señales digitales.

**Potenciómetros A y B**

Las letras A y B pueden utilizarse para indicar el tipo de curva de respuesta del potenciómetro, aunque la convención puede variar entre fabricantes:

Lineal: el cambio físico produce un cambio proporcional de resistencia.
Logarítmico: la resistencia cambia siguiendo una curva, algo habitual en controles de audio.


### **<ins>Raspberry Pi Pico 2 W y voltajes</ins>**

La placa que utilizaré es una Raspberry Pi Pico 2 W aunque durante la clase también revisamos Arduino.

Los GPIO de la Pico trabajan con lógica de 3,3 V:
```
0 V → LOW, 0 o false.
3,3 V → HIGH, 1 o true.
```
No se deben conectar 5 V directamente a un GPIO de la Pico, ya que sus pines no son tolerantes a señales de 5 V y podrían dañarse.

**Push button**

Un push button o pulsador cambia su estado solamente mientras está siendo presionado.
```
Lo presiono → hace contacto.
Lo suelto → regresa a su posición original.
```
**Toggle switch**

Un toggle switch o interruptor de palanca conserva su estado después de moverlo.
```
Primera posición → encendido.
Segunda posición → apagado.
```

### **<ins>El “nodo mal comportado”</ins>**

Cuando un pin de entrada no está conectado claramente ni a un voltaje alto ni a tierra, queda flotante.

Un GPIO flotante puede captar ruido eléctrico del ambiente y entregar lecturas impredecibles:
```
HIGH
LOW
HIGH
HIGH
LOW
```
Para solucionar esto se utilizan resistencias pull-down o pull-up.

### **<ins>Protoboard</ins>**

La protoboard es una placa que permite construir y probar circuitos sin soldar.

Sus orificios no son independientes: debajo de la superficie existen conexiones metálicas que unen determinados grupos.

**Zona central**

En una protoboard común, cada grupo de cinco orificios suele estar conectado internamente:

**a ─ b ─ c ─ d ─ e**

El canal central separa ambos lados. Se utiliza, entre otras cosas, para colocar circuitos integrados con patas a cada lado.

**Rieles de alimentación**

Los rieles laterales suelen utilizarse para distribuir energía:
```
Riel rojo o + → voltaje positivo.
Riel azul, negro o − → GND.
```
### **<ins>Convenciones de colores</ins>**

Los colores de los cables facilitan la lectura y reparación del circuito.

Una convención habitual es:

**Rojo:** alimentación positiva.
**Negro:** GND.
**Azul:** GND o señal, según la convención elegida.
**Amarillo, verde, blanco u otros:** señales.

### **<ins>Pinout</ins>**

El pinout es el diagrama que muestra la ubicación y función de cada pin de una placa.

Un pinout permite identificar:
```
-Pines de alimentación.
-Pines GND.
-Entradas analógicas.
-GPIO digitales.
-Pines con PWM.
-Interfaces de comunicación.
-Funciones especiales.
```
### **<ins>Secciones revisadas en Arduino</ins>**

**Power**

La sección Power contiene pines relacionados con la alimentación, como:
```
5 V
3,3 V
GND
```
Cada uno cumple una función diferente y no deben intercambiarse sin revisar el pinout.

**Digital**

Los pines digitales trabajan principalmente con dos estados:
```
LOW  → 0
HIGH → 1
```
Un botón se conecta normalmente a un pin digital porque representa dos estados: presionado o no presionado.

**Analog In**

Las entradas Analog In, identificadas como A0, A1, etc., permiten leer voltajes variables.

Un potenciómetro se conecta a una entrada analógica porque puede entregar muchos niveles de voltaje entre el mínimo y el máximo.

La entrada analógica permite que la computadora lea una parte del mundo físico que no se limita únicamente a encendido o apagado.

## Montaje del potenciómetro con Arduino
 
# Lectura de un potenciómetro con Arduino

## 1. Conexión del potenciómetro

El potenciómetro posee tres patas:

- Un extremo se conecta a `5 V`.
- El otro extremo se conecta a `GND`.
- La pata central se conecta a la entrada analógica `A0`.

```text
5 V ───── extremo del potenciómetro
A0  ───── pata central
GND ───── otro extremo
```

> **Importante:** esta conexión corresponde a la demostración con un Arduino que trabaja con `5 V`. Con la Raspberry Pi Pico 2 W, el potenciómetro debe conectarse a `3,3 V`, no a `5 V`, para proteger su entrada analógica.

## 2. Código para leer el potenciómetro

```cpp
const int patitaLectura = A0;

int valorLectura = -1;

void setup() {
  Serial.begin(9600);
}

void loop() {
  valorLectura = analogRead(patitaLectura);

  Serial.print("Valor actual: ");
  Serial.println(valorLectura);
}
```

## 3. Declaración del pin

```cpp
const int patitaLectura = A0;
```

Esta línea crea una constante para identificar la entrada analógica utilizada.

- `const`: indica que su valor no cambiará durante la ejecución.
- `int`: indica que guarda un número entero.
- `patitaLectura`: nombre elegido para identificar el pin.
- `A0`: entrada analógica utilizada

## 4. Variable para guardar la lectura

```cpp
int valorLectura = -1;
```

Esta línea crea una variable llamada `valorLectura`.

- `int`: establece que la variable guardará un número entero.
- `valorLectura`: nombre de la variable.
- `-1`: valor inicial.

Se utiliza `-1` porque está fuera del rango normal entregado por `analogRead()` en un Arduino Uno. Por lo tanto, puede representar que todavía no existe una lectura válida.

Es un ejemplo sencillo de **programación defensiva**.

## 5. `setup()` y comunicación serial

```cpp
void setup() {
  Serial.begin(9600);
}
```

La función `setup()` se ejecuta una sola vez cuando comienza el programa.

```cpp
Serial.begin(9600);
```

Esta instrucción inicia la comunicación serial entre Arduino y el computador a una velocidad de `9600` bits por segundo.

Esta velocidad se conoce como *baud rate* en este contexto = (o velocidad en baudios) es el número de cambios de señal o símbolos que se transmiten por segundo en un canal de comunicación.

El monitor serial del computador debe configurarse con la misma velocidad. Si las velocidades no coinciden, la información puede aparecer ilegible.

## 6. `loop()` y lectura analógica

```cpp
void loop() {
  valorLectura = analogRead(patitaLectura);
}
```

La función `loop()` se repite continuamente mientras la placa está encendida.

La instrucción:

```cpp
analogRead(patitaLectura);
```

lee el voltaje presente en la entrada `A0` y lo convierte en un número.

Después, ese número se guarda en la variable `valorLectura`:

```cpp
valorLectura = analogRead(patitaLectura);
```

## 7. Conversión analógica a digital

En un Arduino Uno clásico, el conversor analógico-digital posee una resolución de `10 bits`.

Esto significa que puede representar:

2^{10} = 1024

Por lo tanto, existen `1024` valores posibles:

```text
0 a 1023
```
Al girar el potenciómetro, cambia el voltaje recibido en `A0` y, por lo tanto, también cambia el número entregado por `analogRead()`.

> **Nota:** el rango depende de la placa utilizada. No todas las placas trabajan con una resolución de `10 bits` ni con un voltaje máximo de `5 V`.

## 8. Mostrar la lectura en el computador

```cpp
Serial.print("Valor actual: ");
Serial.println(valorLectura);
```

Estas instrucciones envían información al monitor serial.

### `Serial.print()`

```cpp
Serial.print("Valor actual: ");
```

Muestra la frase sin agregar un salto de línea.

### `Serial.println()`

```cpp
Serial.println(valorLectura);
```

Muestra el valor almacenado en `valorLectura` y después agrega un salto de línea.

El monitor serial mostrará algo similar:

```text
Valor actual: 312
Valor actual: 487
Valor actual: 725
```

## 9. Esperar la conexión serial

En algunas placas se puede agregar:

```cpp
while (!Serial) {
  // Esperar
}
```

El símbolo `!` significa **not** 

Por lo tanto:

```cpp
!Serial
```

significa que la conexión serial todavía no está disponible.

El programa permanecerá dentro del `while` hasta que se establezca la comunicación serial.

## 10. Código completo comentado

```cpp
// Guardamos el pin analógico en una constante.
// "const" indica que no cambiará durante el programa.
const int patitaLectura = A0;

// -1 representa que todavía no existe una lectura válida.
int valorLectura = -1;

void setup() {
  // Iniciamos la comunicación con el computador.
  Serial.begin(9600);

  // En algunas placas podemos esperar la conexión serial.
  while (!Serial) {
    // El programa permanece aquí mientras
    // Serial no esté disponible.
  }
}

void loop() {
  // Leemos el voltaje del potenciómetro
  // y guardamos el resultado.
  valorLectura = analogRead(patitaLectura);

  // Mostramos una frase sin cambiar de línea.
  Serial.print("Valor actual: ");

  // Mostramos el número y agregamos un salto de línea.
  Serial.println(valorLectura);
}
```

## 11. Resumen del funcionamiento

1. Arduino entrega alimentación al potenciómetro.
2. Al girarlo, cambia el voltaje de su pata central.
3. La pata central transmite ese voltaje a `A0`.
4. `analogRead()` convierte el voltaje en un número.
5. El número se guarda en `valorLectura`.
6. `Serial.println()` envía el resultado al computador.
7. `loop()` repite continuamente todo el proceso.

```text
Girar el potenciómetro
          ↓
Cambiar el voltaje en A0
          ↓
analogRead() convierte el voltaje
          ↓
El resultado se guarda en valorLectura
          ↓
Serial.println() lo muestra en el computador
```
