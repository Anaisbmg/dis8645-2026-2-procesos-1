# sesion-03a

## apuntes sesión

Esta sesión se nos entregaron materiales:

* Lector Micro SD
* Pantalla LCD OLED 0,91 I2C
* Protoboards
* Caimanes

* Las pantallas se miden por pulgadas en diagonal.

Revisando antalla LCD OLED 0,91 I2C:
- Tiene 4 pines: GND, VCC, SCL = SCK, SDA
- Sck es serial clock
- El controlador es SSD1306
- Visualización en arduino o esp32

Usaremos bibliotecas (no librerías) compartidas por gente confiable, para Aarón Adafruit es uno de esos.

Algunas pantallas vienen con una dirección, entonces con un arduino podemos alimentar varias pantallas en paralelo.
